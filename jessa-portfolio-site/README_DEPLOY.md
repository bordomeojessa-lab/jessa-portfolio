# Jessa Bordomeo Portfolio Site

This is a Vite + React + Tailwind portfolio site.

## Run locally

```bash
npm install
npm run dev
```

## Build for production

```bash
npm run build
```

## Assets

These files are already placed in `public/`:

- `jessa-photo.png`
- `Jessa_Bordomeo_CV_2026-05-14.pdf`

If you replace your photo or CV later, keep the same file names or update the constants at the top of `src/App.jsx`.

## Recommended deployment

### Vercel

1. Create a GitHub repo.
2. Upload this project folder.
3. Go to Vercel.
4. Click **Add New Project**.
5. Import the GitHub repo.
6. Framework Preset: **Vite**.
7. Build Command: `npm run build`.
8. Output Directory: `dist`.
9. Deploy.

### Netlify

1. Create a GitHub repo.
2. Upload this project folder.
3. Go to Netlify.
4. Click **Add new site > Import an existing project**.
5. Select the GitHub repo.
6. Build Command: `npm run build`.
7. Publish Directory: `dist`.
8. Deploy.
